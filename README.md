# Make-Code-Sim
MakeCode-inspired Circuit Playground simulator for learning block-based programming.

## Quick start
Open `index.html` in a local web server to load Blockly and the simulator UI.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## What’s included
- MakeCode-style workspace with block categories (loops, variables, functions, etc.).
- Circuit Playground LED ring simulator with button and sensor controls.
- Guided lesson panel with beginner-friendly challenges.
